# 프로그램 연동 규칙 — 어느 기록이 어느 계정에 세이나

한 PC 에서 계정을 갈아 가며 쓰면 **Claude 기본 폴더(`~/.claude`) 의 기록은 누구 것인지 모릅니다** —
로그 줄에는 계정이 없기 때문입니다. 이 문서가 **주인을 가르는 순서 · 연동 이력의 형식 · 지난 기록을
건드리지 않는 이유**의 정본입니다.

구현은 [ClaudeProgramRouter.cs](../200.Source/costats.Infrastructure/Providers/ClaudeProgramRouter.cs) ·
[ClaudeProgramLinks.cs](../200.Source/costats.Infrastructure/Providers/ClaudeProgramLinks.cs) 두 곳이고,
설정 화면은 [SettingsViewModel.BuildProgramLinks](../200.Source/costats.App/ViewModels/SettingsViewModel.cs) 입니다.

---

## 1. 주인을 가르는 순서 — 위에서부터, 먼저 맞는 것이 이깁니다

`ClaudeProgramRouter.SourceOf(entrypoint, sessionId, at)` 가 로그 줄 하나마다 **기록 단위(source)** 를
정하고, `OwnerOf(source)` 가 그것을 **자리(providerId)** 로 바꿉니다.

| # | 줄의 정체 | 주인을 어디서 아나 | 기록 단위 |
|---|---|---|---|
| 1 | VS Code · CLI 세션 중 앱이 **처음 본 순간을 적어 둔** 것 | `claude-cli-sessions.json`(ClaudeCliSessions) | `claude-vscode@<계정UUID>` · `cli@<계정UUID>` |
| 2 | 데스크톱 앱 **에이전트 모드** | 세션 폴더 경로의 계정 UUID | `local-agent@<계정UUID>` |
| 3 | 데스크톱 앱 **Code 탭** | 앱이 남긴 세션 메타의 `cliSessionId` | `claude-desktop@<계정UUID>` |
| 4 | **위에서 주인을 못 찾은 줄** | **그 줄의 시각에 유효했던 연동 이력**(§2) | `<프로그램>@<계정UUID>` |
| 5 | 연동 이력이 **시작되기 전** 줄 | 옛 「프로그램 연동」 표 `AppSettings.ProgramAccounts` | `<프로그램>`(계정 없음) |

- **4번이 이번에 더해진 자리입니다.** 그전에는 4·5가 한 덩어리라 표를 바꾸면 **지난 기록까지 통째로**
  새 주인을 따라갔습니다.
- 계정 UUID 가 **이 PC 에 등록된 자리 중 어느 것도 아니면** 4번을 쓰지 않고 5번으로 내려갑니다 —
  셀 곳이 없는 기록을 엉뚱한 자리에 붙이지 않기 위해서입니다.
- ⛔ **5번의 `ProgramAccounts` 는 화면에서 더 이상 고치지 않지만 지우지도 않습니다.** 지우면
  이력 이전 기록의 주인이 조용히 바뀝니다.

## 2. 연동 이력 — `program-links.json`

```text
%LOCALAPPDATA%\JHJ_AI-Usage-Monitor\program-links.json
```

```json
[
  { "Program": "cli",            "Account": "3fef7cb1-42d9-…", "From": "2026-10-10T02:11:40+00:00" },
  { "Program": "claude-desktop", "Account": "e7eb908c-7286-…", "From": "2026-10-10T02:11:40+00:00" }
]
```

- **쌓기만 하고 지우지 않습니다.** 한 줄 = 「이 시각부터 이 프로그램은 이 계정 것」이고, 다음 줄이
  나올 때까지 유효합니다. 4,000줄을 넘으면 앞에서부터 자릅니다.
- **값이 자리 이름이 아니라 계정 UUID 입니다.** 자리를 지웠다 다시 만들어도, 같은 계정으로 돌아오면
  **같은 이력 파일로 이어집니다**(`history\claude-program\cli@<UUID>.json`).
- **직전과 같으면 쓰지 않습니다.** 갱신마다 파일이 커지지 않습니다.
- 로그아웃·읽기 실패로 계정을 모를 때는 **아무것도 남기지 않습니다** — 직전 연동이 그대로 이어집니다.

## 3. 「지금 로그인한 계정」을 프로그램마다 따로 읽습니다

| 프로그램 | 어디서 읽나 | 왜 거기인가 |
|---|---|---|
| `claude-vscode` · `cli` | `ClaudeHomeIdentity.Read()` — `~/.claude.json` 의 `oauthAccount` | 둘 다 `~/.claude` 를 씁니다. 데스크톱이 덮어쓴 값은 `Read()` 가 이미 걸러 냅니다 |
| `claude-desktop` | 세션 메타를 **가장 최근에 쓴** 계정 폴더(`ClaudeDesktopSessions.NewestAccount()`) | 데스크톱 앱은 홈 파일을 CLI 와 함께 쓰므로 홈 값으로는 가려지지 않습니다 |

- ⚠️ **함정** — 데스크톱 판정은 파일 수정 시각 기준입니다. 옛 계정의 세션을 지우면 그 계정의
  `deleted_*` 메타가 새로 쓰여 **한 주기 동안 그쪽이 「최근」으로 잡힐 수 있습니다.**

## 4. 언제 다시 재나

**설정 › 일반 「갱신 주기」와 같습니다**(기본 5분). 토큰·사용량을 읽는 그 주기입니다.

| 때 | 부르는 곳 |
|---|---|
| 갱신마다 — **로그를 읽기 직전** | `UsageLogScanner.ScanClaudeAsync` · `ExpenseAnalyzer.AnalyzeClaudeAsync` 의 `SyncLinksIfDue()` |
| 설정 창을 열 때 | `SettingsViewModel.RefreshAccounts()` 의 `SyncLinks()` |
| 앱 시작 때 · 연동을 손으로 바꿀 때 | `ClaudeProgramRouter.Configure()` 끝의 `SyncLinks()` |

- **읽기 직전이어야 합니다.** 뒤에 부르면 이번 갱신의 새 줄이 옛 연동으로 세입니다.
- 한 번 갱신하면 자리 수만큼 소스가 돌므로 **30초 안의 재호출은 걷어냅니다**(`SyncGap`).
  갱신 주기의 최소값이 1분이라 주기마다 정확히 한 번 돕니다.

## 5. 설정 화면 — 「자동」이 기본입니다

```text
데스크톱 앱    [ 자동 · atisys.ai · atisys.ai@gmail.com  ▾ ]
VS Code        [ 자동 · jhj · jhj@atisys.co.kr           ▾ ]
터미널 CLI     [ 자동 · jhj · jhj@atisys.co.kr           ▾ ]
```

- 첫 칸 `자동`(`ProgramLinkRow.AutoId`)이 기본이고, **지금 이 PC 에 로그인한 계정을 따라갑니다.**
- 아래에서 계정을 고르면 **그 줄만 고정**됩니다 — `AppSettings.ProgramAccountPins` 에 남고,
  고정된 줄은 그 자리의 계정 UUID 로 이력에 기록됩니다.
- **연동을 바꿔도 지난 기록은 옮겨 가지 않습니다.** 바뀐 시각 이후의 줄부터 새 주인이 됩니다.

## 6. 팝업 계정 카드의 「연동됨 · …」

`ProviderPulseViewModel.LinkedProgramsText` 가 `ClaudeProgramRouter.CurrentLinks()` 로 채웁니다 —
**지금** 그 계정으로 세는 프로그램만 보입니다. 연동이 옮겨 가면 그 카드에서 사라지고 새 계정 카드에 붙습니다.

- 머리글은 이름·유형·요금제와 폭을 다툽니다 — 셋이 다 붙으면 `…` 로 줄이고 전체는 손가락 설명으로 보입니다.

## 7. 옛 키와 새 키가 같은 날을 두 번 세지 않는 이유

이력이 시작되면 같은 프로그램의 기록이 **옛 키(`cli`)와 새 키(`cli@<UUID>`)** 로 갈립니다.
둘이 같은 자리에 세여도 **날이 겹치지 않습니다** — `SourceOf` 가 줄의 시각으로 갈라 주고,
`UsageHistoryStore` 가 키마다 한 번 「로그가 있는 날부터」를 새 값으로 갈아 끼우기 때문입니다.
전환이 일어난 그 하루만 **오전은 옛 키 · 오후는 새 키**로 나뉘어, 합은 그대로입니다.

## 8. 진단 보고서에서 보는 법

설정 › 정보 › 「진단 정보 복사」에 다음이 함께 실립니다(UUID 는 가려집니다).

```text
- 손으로 고정한 연동: 없음(전부 자동)
- 연동 이력 2줄: 2026-10-10 02:11 cli → 3fef7cb1… · 2026-10-10 02:11 claude-desktop → e7eb908c…
```

## 9. 이 규칙을 고칠 때 함께 볼 곳

| 고치는 것 | 함께 보는 곳 |
|---|---|
| 표에 서는 프로그램을 더한다 | `ClaudeProgramRouter.LinkedPrograms` · `SettingsViewModel.ClaudePrograms` · `ProviderPulseViewModel.ProgramGroups`·`LinkedProgramLabels` — **네 곳이 같은 키를 씁니다** |
| 기록 단위(source) 형식을 바꾼다 | ⛔ `UsageHistoryStore.ProgramKey` 가 **파일 이름으로 씁니다** — 영숫자·`-`·`_`·`@` 말고는 `_` 로 접혀 되읽을 때 주인을 못 찾습니다 |
| 이력 파일 자리를 옮긴다 | `ClaudeProgramLinks.FilePath` 한 곳. 설치 폴더 **밖**이라 업데이트해도 남습니다 |
